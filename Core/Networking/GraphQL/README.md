# MTGGraphQL codegen

Price history comes from [MTGGraphQL](https://mtgjson.com/mtggraphql/), a GraphQL
API over the MTGJSON data sets. It is in beta and access tokens are issued to
Patreon subscribers on Discord.

The Swift types for `CardPriceHistory.graphql` are generated by Apollo and are
**not committed** in a working state yet — `ApolloPriceHistoryClient.swift` is
compiled out behind `#if MTGGRAPHQL_GENERATED` until you run the two steps below.
Everything else (models, caching, mock, chart view) builds and runs today against
`MockPriceHistoryClient`.

## 1. Fetch the schema and generate

Codegen validates operations against a real schema, so introspect once from your
dev machine using your own token:

```bash
cd Core/Networking/GraphQL
MTGGRAPHQL_TOKEN=xxxxx ./bootstrap.sh
```

That installs `apollo-ios-cli`, downloads `schema.graphqls`, and generates into
`../Sources/PriceHistory/Generated/`. The token is only ever written to
`apollo-codegen-config.local.json`, which is gitignored and deleted on exit.

Commit `schema.graphqls` — the schema is not a secret, and having it in the repo
means codegen works on CI and on a fresh clone without a token.

Generated types are embedded in the `Networking` target (`embeddedInTarget`), so
there is no extra module to import and no separate SPM package. Afterwards run
`tuist generate`; Tuist globs sources at generation time, so new files are
invisible to xcodebuild until it reruns.

`bootstrap.sh` also flips `graphQLGenerated` to `true` in
`Core/Networking/Project.swift` and reruns `tuist generate`, which is what
compiles `ApolloPriceHistoryClient` in.

That flag is a literal in the manifest rather than a `FileManager` check on the
`Generated` directory, and it has to be: **Tuist caches manifest evaluation by
content hash**, so a manifest that only reads the filesystem is never
re-evaluated after codegen and the flag would silently never turn on. Editing the
line is what busts the cache. (This also means `tuist generate` can serve a stale
project after any change that doesn't touch a manifest.)

## Verifying the live response

`PriceHistoryIntegrationTests` hits MTGGraphQL for real and asserts the payload
maps to a chartable series. It is gated on `MTGGRAPHQL_TOKEN`, so it is skipped
everywhere that variable is absent, including CI.

`xcodebuild test` cannot run it on this machine: the deployment target is iOS
27.0 and the newest installed simulator runtime is 26.5. Either install an iOS 27
runtime, or use the wrapper, which builds the pure-Foundation slice as a throwaway
SwiftPM package on macOS:

```bash
cd Core/Networking/GraphQL
MTGGRAPHQL_TOKEN=xxxxx ./verify-live.sh
```

Set `MTGGRAPHQL_URL` to exercise the deployed proxy instead of MTGJSON directly.

## Schema notes

Taken from the fetched `schema.graphqls`, since the first draft of the operation
guessed wrong:

- The Scryfall id filter is **nested under `identifiers`**, not on the filter
  root: `filter: { identifiers: { scryfallId_eq: $scryfallId } }`.
  `CardEntityFilterInput` itself only exposes `uuid`, `name`, `artist`,
  `setCode`, `type`, `asciiName` and `isReprint`.
- `Query.cards` returns `[Card!]!` and `Card.prices` is `[CardPrices!]!`, so an
  unknown card yields an empty array rather than null.
- On `CardPrices` every field except `currency` is non-null; `price` is a `Float`
  and `date` is a `String` in `YYYY-MM-DD`. `format` is `paper` or `mtgio`.
- `Card.prices` takes no arguments, so provider / finish / list-type filtering
  happens client-side in `PriceHistoryMapper`. The top-level `Query.prices` field
  does filter server-side but keys off the MTGJSON `uuid`, which would cost a
  second round trip from a Scryfall id.

`Tools/mtggraphql-proxy/src/worker.js` rebuilds this same operation server-side
rather than forwarding the client's query text, so its copy must **explicitly
request `__typename`** on `cards` and `prices`. Apollo iOS adds `__typename` to
this document automatically and its generated response types require it, but the
proxy's hand-written copy does not get that for free — omitting it makes every
`apollo.fetch` fail to decode with the response silently swallowed by the
chart's `try?`. Keep the two operations in step when changing either.

## Rate limits

500 requests/hour per access token, 1,000/hour per IP. The proxy caches for six
hours and `CachingPriceHistoryClient` memoises on the device, so normal browsing
costs roughly one upstream request per card per six hours across all installs.
